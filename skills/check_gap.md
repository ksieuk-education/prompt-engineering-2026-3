# Проверка длительности

Если вопрос только о времени между двумя звуками на копии, выбери обе метки в описи и вызови tape_span. Для такого измерения достаточно счетчика самой записи. Для сравнения с эфиром нужны еще отметки в журнале.

1. Найди два звука, которые независимо отмечены на пленке и в эфирном журнале.
2. Вызови compare_span. Приведи обе длительности и их разность в секундах.
3. Для вывода о содержимом или причине расхождения найди документ о происхождении копии. Разница интервалов сама по себе не указывает, где именно изменили запись.
