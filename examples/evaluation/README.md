# Эксперименты с архивистом

До каждого прогона для проверочных вопросов задавали ожидаемые страницы, фрагменты или показания часов. Ниже приведены результаты, ошибки и условия повторения. Команды выполняются из корня репозитория. [Описание лабораторной](../../README.md)

## Повтор на другой катушке

На вопрос о позиции музыкальной отбивки Phi однажды вернула похожий звук с другой катушки. Для явных вопросов о счетчике архивист теперь читает опись выбранной копии. Если в ней два удара, он уточняет, о каком идет речь. После ответа «Второй» можно спросить «А в эфире во сколько прозвучал этот же удар?» и получить 19:05:37 из журнала. До изменения Qwen прошла 5/10 таких реплик, Phi — 0/10. После изменения Qwen, Phi и Gemma прошли по 10/10. В браузере проверили открытие источника A2 и воспроизведение именно с 00:25. [Первый прогон Qwen](positions/qwen25-before.json) · [Первый прогон Phi](positions/phi4-mini-before.json) · [Повтор на Qwen](positions/qwen25-after.json) · [Повтор на Phi](positions/phi4-mini-after.json) · [Повтор на Gemma](positions/gemma3-1b-after.json) · [Браузерная проверка](positions/browser.json)

В первом прогоне архивист находил три ноты на другой катушке, затем выдавал время контрольного тона исходной записи. Мы добавили сверку по фонограмме и двум отдельным описям. Вопрос об эфирном времени ссылается на конкретную пару фрагментов, и каждая сторона получает время только из документов своего дела. Когда на катушке есть два одинаковых удара, можно выбрать секунду. В серии есть также обратный переход из третьего дела в первое и вопрос после безуспешного поиска. [Первоначальные ответы](reels/before.json) · [Прогон Qwen](reels/qwen25-repeats.json) · [Прогон Gemma](reels/gemma3-1b-repeats.json) · [Инструмент](../../studio/repeats.py)

## Сверка двух реальных записей

Кнопка «Сверка записей NASA» открывает две опубликованные версии переговоров Apollo 11 и другую передачу той же миссии для контроля. Выберите образец с 2,50 секунды короткой записи. Корреляция по отсчетам дает всего 0,144. Сравнение изменений энергии в частотных полосах предлагает проверить участок с 3,41 секунды расширенной записи (0,773 при пороге 0,70). Его можно сразу прослушать или передать архивисту кнопкой под результатом. Для другой передачи лучший спектральный результат в этом опыте равен 0,418.

Всего проверили пять положений образца длительностью по 1,6 секунды. Спектральный порог прошли три окна из пяти для расширенной версии и ни одного для контрольной записи. Окна частично перекрываются. Это небольшой опыт на конкретных оцифровках, и коэффициент служит подсказкой для прослушивания. Источник аудио — коллекция NASA Historical Sounds. [Скриншот сверки](../../images/06-public-audio.png) · [Источники и контрольные суммы](../../data/field/SOURCES.md) · [Все измерения](public-audio.json)

Таким же способом можно сравнить собственные WAV. Команда ниже повторяет опыт на файлах из репозитория.

```bash
poetry run python -m tools.compare_recordings data/field/eagle-short.wav data/field/eagle-extended.wav data/field/small-step.wav --at 0.40 0.75 1.50 2.50 3.40
```

Ту же сверку можно поручить архивисту. Напишите «Сверь две записи NASA по спектру», затем «с 2,50 с» и «А теперь сравни с другой репликой о первом шаге». И диалог, и форма обращаются к инструменту `compare_public`. У Qwen и Gemma прошли все четыре проверки, включая запрос недостающей секунды и образец за пределами записи. [Прогон Qwen](final/qwen25-field.json) · [Прогон Gemma](final/gemma3-1b-field.json)

### Что меняется при другой скорости копии

В том же окне выберите «Учебной копией с другой скоростью» и начало 2,50 с. Эту копию мы изготовили из короткого WAV с задержкой 0,57 с, изменением скорости, инверсией полярности и слабым шумом. По обычной волне получается 0,246. После перебора скоростей программа находит образец на 3,0282 с с коэффициентом 0,977. Оценка скорости +1,70 % совпадает с внесенным изменением. Кнопка рядом с результатом воспроизводит соответствующий участок копии с ее фактической длительностью. [Как изготовлена копия](../../tools/evaluate_speed.py) · [Полифазная передискретизация SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)

Для проверки взяли две разные записи речи и по два фрагмента в каждой. Обычная волна пропустила все 12 окон на копиях с тремя измененными скоростями. Перебор в пределах ±4 % нашел все 12 в пределах 3 мс от известной позиции. Четыре сравнения с другой передачей и четыре за пределами диапазона не прошли порог. На двух подлинных оцифровках сообщения о посадке перебор также не дал совпадения по волне в трех проверенных окнах. Там подсказку для прослушивания по-прежнему дает спектр. [Измерения и параметры опыта](speed-scan.json)

В диалоге начните со «Сравни образец NASA с 2,50 с с учебной копией с учетом скорости». Можно попросить повторить без поправки и затем выбрать другую передачу. В пяти живых проверках архивист сохранил исходную секунду, применил нужный режим и вернул измерения для выбранного файла. [Прогон диалога о скорости](witness/qwen25-speed.json)

## Поиск в стенограмме Apollo 11

В окне сверки откройте «Найти фразу в стенограмме» и введите `the Eagle has landed`. На странице 317 сообщение о посадке записано за командиром в 102:46:04 от старта миссии. На той же странице есть ответ Хьюстона двумя секундами позже. В диалоге это можно проверить вопросом «Что ответили затем?». Для запроса по-русски попробуйте «Найди в стенограмме Apollo 11 слова про один маленький шаг для человека». Он открывает страницу 377. Позиции в аудиоплеере и время от старта миссии отсчитываются от разных точек. [Страница в монтажной](../../images/07-transcript.png) · [Опубликованная стенограмма](https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/a11transcript_tec.html)

В комплекте 624 пронумерованные страницы. В основном OCR нашлось 8 435 размеченных реплик. На странице 491 вместо текста стоит помета о поврежденном файле. Мы нашли полный скан, который архивист NASA Колин Фрайз передал составителям журнала, сверили с ним еще 17 реплик и добавили их в поиск. Всего получилось 8 452. Введите `491` в том же поле, чтобы открыть страницу и сравнить наборный текст со сканом. [Источник дополнительной страницы](https://apollojournals.org/alsj/a11/a11trans.html) · [Скан в репозитории](../../data/field/nasa-page-491.pdf)

По английским словам SQLite FTS5 сначала ищет фразу и затем пробует значимые слова вместе. Для дословной цитаты в диалоге архивист дополнительно сверяет порядок и форму каждого слова. Если указан автор, поиск сначала идет по репликам этого говорящего. Открытая страница показывает соседние реплики и подсвечивает найденное место. Для чтения и прямого поиска достаточно запустить приложение. В русском диалоге языковая модель переводит описание, а затем сравнивает выбранную цитату с вопросом. Если в Ollama есть `embeddinggemma:300m`, к поиску по словам добавляется сравнение английских и русских векторов. Для этого достаточно выполнить `ollama pull embeddinggemma:300m`. Готовый индекс лежит в репозитории. При независимой локальной пересборке совпали все 8 452 вектора по 768 целочисленных компонент. [Проверка пересборки](restored/rebuild-check.json) [Как работает FTS5](https://sqlite.org/fts5.html) · [Модель поиска](https://huggingface.co/google/embeddinggemma-300m)

В первом опыте обычный поиск с переводом дал 3/7 у Qwen2.5 и 2/7 у Gemma 3 1B. На вопросе о пыли Qwen выбрала похожее описание поверхности на странице 385. Правильная строка со страницы 377 объясняет, с чем Армстронг сравнил пыль именно на подошвах. После подключения эмбеддингов выяснилось, что правильную цитату иногда отбрасывала последняя проверка. Мы изменили вопрос к модели. Говорящий и расположение реплики уже известны из архива, поэтому модели достаточно проверить, отвечает ли фрагмент на содержательную часть запроса. [Исходная Qwen](qwen25-paraphrase-fts.json) · [Исходная Gemma](gemma3-1b-paraphrase-fts.json) · [Ранги кандидатов до проверки цитаты](embeddinggemma-ranks.json)

Среди отложенных вопросов Qwen нашла приветствие «землянин» и сравнение слышимости с разговором в гостиной. Она пропустила свидетельство о сине-зеленом лазере. Gemma сочла радиопроверку свидетельством подключения к Wi-Fi. Восьмерка задач со стенограммой в основном проверяет навигацию и поиск английских цитат. Семь и пять вопросов проверяют именно русские пересказы. В отдельном прогоне все семь проверок страницы 491 и границ между часами файла и миссии прошли на Qwen. [Проверка восстановленной страницы и двух часов](restored/qwen25-edition.json)

В первом запуске Qwen3-30B на некоторых переводах расходовала все 220 токенов до выдачи JSON. Теперь архивист один раз повторяет такой вызов с большим лимитом. На семи русских пересказах медиана ожидания составила 19,64 секунды у Qwen3-30B и 4,61 у Qwen2.5. Обе дали одинаковое число правильных ответов во всех трех сериях из таблицы. [Прогон Qwen3-30B до исправления](final/qwen3-30b-grounded-paraphrase.json)

В поле «На странице» можно ограничить поиск конкретным листом. Например, `three cups of coffee` открывает страницу 87, где Коллинз рассказывает, сколько кофе они приготовили. На странице 578 он перечисляет собственный завтрак и говорит `two cups of coffee`. Если в вопросе о завтраке указать три чашки, архивист показывает число со страницы 578 и дает открыть строку целиком. Раньше вопрос с номером листа возвращал только число реплик на странице. Из шести проверок такого поиска тогда прошла одна, после доработки у Qwen2.5 прошли все шесть. ### Что начинается в указанную секунду

До изменения запрос о времени 102:46:04 приводил на страницу 218 к сообщению о телеметрии. Теперь архивист находит на странице 317 слова Армстронга о посадке, а в интервале 102:45:59–102:46:06 показывает все три реплики. Верхняя и нижняя границы включены. Если отметка попала между началами строк, в ответе остается открытым вопрос, продолжалась ли в эту секунду речь. Для этого поиска в диалоге и в читальном окне достаточно локальной стенограммы. На 14 заранее выписанных вопросах и уточнениях было 0/14, стало 14/14. [Вопросы и первые ответы](mission/before.json) · [После изменения](mission/with-clock.json)

На странице 253 у ответа «Roger. Copy. Out.» в скане указан день 02, а у соседних строк — 03. Отсюда два попадания на запрос `059:26:41`, одно из них на странице 182. Монтажная показывает обе записи и соседние времена спорной строки. При выборе двух одинаковых «Right.» на странице 491 раньше подсвечивались оба ответа Коллинза. Теперь ссылка ведет к конкретной строке. Проверили адреса всех 8 452 реплик и открытие повторов в трех браузерах. [Две страницы с одинаковой меткой](../../images/09-mission-clock.png) · [Скан листа 253](../../data/field/nasa-page-253.pdf) · [Проверка в браузерах](mission/browser.json)

Сравнение с изображением листа дало и обратный пример. На странице 234 в HTML у ответа Олдрина стоит пятый день, а на скане хорошо виден третий. На странице 320 у слов Коллинза в HTML указан второй день, на скане — четвертый. Для этих двух строк архивист показывает оба чтения. Найти каждую можно по любой из меток, а в широком интервале она появляется один раз. На пяти вопросах, включая уточнение в диалоге, сверка обеих версий улучшила результат с 0/5 до 5/5. [Два исходных листа](../../data/field/nasa-clock-variants.pdf) · [До сверки](mission/editions-before.json) · [Со сверкой](mission/editions.json)

### Две реплики или весь интервал

В 102:45:59 Армстронг вызывает Хьюстон, в 102:46:04 сообщает о посадке, в 102:46:06 Хьюстон отвечает. Поиск «что сказано на 102:45:59 и 102:46:06» раньше выдавал все три строки. Теперь можно поставить запятую между метками или спросить о них в диалоге. Монтажная показывает только запрошенные строки и указывает отдельно, сколько началось на каждой метке. Запрос «между» по-прежнему дает весь интервал. На вопрос «сколько секунд прошло» архивист вычисляет разницу показаний. Даже когда начало реплики не попало ни на одну из меток, разницу часов можно посчитать. Длительность речи по этим двум числам установить нельзя.

На девяти вопросах проверяли порядок двух меток, разницу в 0, 3 и 7 секунд и строку, которую разные издания датируют по-разному. До изменения полностью прошел один сценарий, после — девять. ### Кто произнес фразу

Если попросить слова Коллинза «the Eagle has landed», архивист проверит реплики Коллинза и затем дословно поищет те же слова среди всех говорящих. Фраза нашлась на странице 317 с обозначением CDR (TRANQ), за командиром Нилом Армстронгом. После этого можно спросить «А когда?» или открыть следующую строку. Обозначение CC в ответе Хьюстона устанавливает роль оператора. Личное имя на этой строке не напечатано. На восьми проверках авторства, коротких уточнений и предмета цитаты Qwen2.5 улучшила результат с 4/8 до 8/8. [До](witnesses-before.json) · [После](witness/qwen25-witnesses.json)

В опыте с лазером поиск уже выдавал страницу 123, но модель предпочла короткую строку о цвете. Теперь после отказа архивист может проверить еще одну строку с редким сочетанием из запроса. Слова для повторной проверки берутся дословно из стенограммы. На повторе пяти уже разобранных вопросов Qwen2.5 нашла все пять, включая описание лазера. На шести отдельно подготовленных вопросах осталось 5/6. Она правильно отвергла третью чашку кофе в пересказе о завтраке и пропустила предложение записать Олдрина на соревнование по поеданию овсянки. [Повтор пяти вопросов](witness/qwen25-paraphrase-new.json) · [Новые шесть вопросов](witness/qwen25-holdout.json)

На тех же шести новых вопросах Gemma 3 1B первоначально прошла 3/6, Qwen3-30B — 4/6. Старшая модель нашла реплику Коллинза про овсянку. Она также приняла предложение поучаствовать за сообщение о победе и указала строку про две чашки кофе для запроса о трех. После сверки чисел и деталей события Qwen3-30B стала приводить завтрак на странице 578 как контрпример и получила 5/6. Ошибка с победой в соревновании сохранилась. ### Может ли готовая модель проверить утверждение

Мы дали двум открытым классификаторам DeBERTa 10 подлинных реплик и по два английских утверждения к каждой. Одно передавало смысл, другое меняло деталь. Строку источника и английскую формулировку задавали вручную, поэтому опыт проверяет один шаг после поиска. Без подписи говорящего модели xsmall и small дали 15/20 и 16/20. С подписью получилось 16/20 и 17/20. Обе распознали подмену двух чашек кофе тремя, но приняли кратер размером с футбольное поле за кратер размером с мяч. В монтаже решение о подтверждении цитаты осталось за архивистом и сверкой слов источника. [Все четыре прогона](nli) · [Модель и ее обучение](https://huggingface.co/cross-encoder/nli-deberta-v3-small) · [Повторить опыт](../../tools/evaluate_entailment.py)

## Сравнение локальных моделей

В исходной версии Qwen2.5 ответила на три из шести новых вопросов. После доработки мы добавили к этим шести вопросам еще три задания на поиск звука. Отдельно повторили первые шесть вопросов лабораторной и попробовали шесть новых формулировок. Для сравнения ответы проверяет отдельная программа по числам, источникам и вызовам инструментов. Посторонний вопрос в наборе из девяти отсекается до вызова LLM. [Исходный прогон](before-qwen25.json) · [Критерии](../../tools/evaluate.py)

## Как повторить проверку

Первая команда проверяет файлы, поиск, измерения и переходы между репликами локально. Для живых диалогов запустите монтажную и Ollama. Программа оценки сохраняет текст ответа, источники, вызванные инструменты, время ожидания и результат сверки. Набор `transfer` содержит дополнительные формулировки для учебных дел, `field` проверяет сравнение реальных записей, `transcript` проверяет работу со стенограммой.

```bash
poetry run python -m pytest -q
poetry run python tools/run_examples.py --out /tmp/archive-check

poetry run python tools/evaluate.py --suite positions --label local --out /tmp/archive-positions.json
poetry run python tools/evaluate.py --suite field --label local --out /tmp/archive-field.json
```

```bash
poetry run python -m pip install --target /tmp/archive-nli-deps onnxruntime tokenizers huggingface-hub
```
