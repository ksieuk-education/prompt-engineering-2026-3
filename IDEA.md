# Вторая дорожка

## Замысел

Фоноархив получил катушки и разрозненные бумаги. Нужно ответить на вопрос об эфире, открыть свидетельство и послушать звук, к которому оно относится. Тема и три учебных дела разработаны для этой работы.

## План

1. Подготовить три фонограммы с метками и по четыре коротких документа. В одном деле сдвиг можно измерить, в другом можно сравнить два интервала, в третьем точного времени установить нельзя.
2. Связать локальную модель с поиском по документам и методическими памятками через LangGraph. Расчет времени поручить инструментам отдельного MCP-сервера.
3. Сделать браузерную монтажную. Дать слушателю выбрать дело, перемотать запись к метке, задать вопрос и открыть источник из ответа.
4. Выполнить контрольные диалоги на настоящей модели. Сохранить результаты, сделать скриншоты и записать демонстрацию около трех минут.

## Исходный запрос

> теперь сделай след лабу в ~/projects/ueba/prompt-engineering-2026/prompt-engineering-2026-3  
> напиши план для себя и по нему иди

Тема выбрана по заданию «Мой агент». Критерии реализации и формат сдачи опубликованы кафедрой. [Задание](https://github.com/MAILabs-Education/MyAgent)

## Рабочие вопросы к агенту

- Во сколько прозвучал позывной и насколько он разошелся с планом?
- Почему он опоздал? Можно ли назвать причину?
- Сколько секунд не хватает между двумя ударами?
- Можно ли установить, что именно исчезло?
- Можно ли установить точное эфирное время заставки?
- Какой документ помог бы восстановить время?

Эти вопросы предназначены для проверки программы. Инструкции, которые модель получает во время работы, находятся в `studio/agent.py` и `skills/`.

## Продолжение исследования

В следующем цикле задача состояла в том, чтобы испытать другие локальные модели и проверить, чем архивисту может помочь готовый компонент. Сначала зафиксировали шесть новых вопросов и прогнали исходный код первой версии лабораторной. Затем добавили поиск по звуку на основе SciPy и три проверки с заранее известными результатами. В тестовом наборе для корреляции есть также искусственный фрагмент с инверсией сигнала, изменением уровня и шумом. Его положения задает тест, а поиску они неизвестны. [Вопросы и критерии](tools/evaluate.py) · [Тесты по волне](tests/test_audio_search.py)

На опубликованных записях NASA сравнили поиск по волне и по спектру, затем связали находки с технической стенограммой. По английской фразе или ее описанию на русском можно открыть конкретную страницу, прочитать соседний ответ и сверить говорящего. На этом опыте отдельно проверяли счетчик аудиофайла и время от старта миссии. [Аудио и текст из архива NASA](data/field/SOURCES.md)

Отправной точкой для этой серии был вопрос «можем еще что-то улучшить и проверить? продолжай работу, исследуй, пока я не остановлю. можешь пробовать другие ллм. возможно для этой лабы подойдет найти что-то готовое и допилить». Для выбора инструмента агент получает схему JSON и список наблюдений. Для поиска по русскому описанию мы отдельно просим модель перевести предмет вопроса на английский, а затем выбрать цитату из выданных реплик. Критерии оценки остаются в тестовой программе. [Промпты архивиста](studio/agent.py) · [Перевод запроса и проверка цитаты](studio/transcript_agent.py) · [Контрольные вопросы](tools/evaluate.py)

Два уточнения выявили разные ошибки с контекстом. «Можно ли установить эфирное время у найденного повтора на другой катушке?» требует открыть дело повтора. «Где на странице 578 сказано, что за завтраком выпили три чашки кофе?» требует удержать и страницу, и обстоятельства. Три чашки упоминаются на другом листе в другом разговоре. Эти вопросы вошли в отдельные контрольные серии. [Сверка двух катушек](studio/repeats.py) · [Проверка числа в цитате](studio/transcript_evidence.py)
